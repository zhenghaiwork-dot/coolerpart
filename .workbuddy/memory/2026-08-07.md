## 产品描述多语言本地化

### 问题诊断
- 用户反馈：阿语产品页内容全是英文
- 调查发现：模板文字已全部用 `__()` 翻译（之前的 session 做的），产品名称也已在 ui.ts 字典翻译
- **唯一缺失**：产品描述（description）没有翻译 — `getProductDescription()` 查 `product.desc.{slug}` 在 ui.ts 中不存在，回退英文

### 架构发现：i18n 方式已变更
- 之前记忆说用 MDX frontmatter `nameAr`/`nameEs` 字段，但实际代码已改为 **ui.ts 字典查找** 模式
- `getProductName(product, locale)` → 查 `product.name.{slug}` in ui.ts
- `getProductDescription(product, locale)` → 查 `product.desc.{slug}` in ui.ts
- `getProductSpec(slug, label, value, locale)` → 查 `product.spec.{slug}.{label}` in ui.ts
- `getProductTypeName(typeSlug, locale)` → 查 `product.type.{typeSlug}` in ui.ts
- MDX frontmatter 的 `nameAr`/`nameEs` 字段仍存在但已被 getter 函数忽略（vestigial）

### 实施内容
1. **ui.ts**: 添加 64 条 `product.desc.{slug}` 条目（en + es），插入在 `product.name.*` 和 `product.type.*` 之间
2. **ProductDetailPage.astro**: 
   - StructuredData `description: product.description` → `description: displayDesc`
   - SEO metadata `description: \`${product.description}...\`` → `\`${displayDesc}...\``
3. **MotorReplacementPage.astro**: `{p.description}` → `{getProductDescription(p, locale)}` + import 修复
4. **WaterPumpReplacementPage.astro**: 同上
5. **ProductCard.astro**: 已在之前 session 修好（用了 `getProductDescription`）✅
